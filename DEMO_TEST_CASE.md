# Demo Test Case

Use one of the linked customer-claim cases, such as the high-value international transaction.

Expected indicators may include:
- unusually high amount
- international transaction
- new location
- new merchant
- higher-risk category
- rapid repeated transaction

Suggested flow:
1. Review transaction.
2. Review customer history.
3. Review claim.
4. Complete checklist.
5. Enter evidence summary.
6. Make a decision.
7. Review simulated chargeback eligibility.
8. Save the case.
9. Download the HTML case report.
